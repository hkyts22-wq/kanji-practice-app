# 3年生 かんじ書きとりトレーナー

小学3年生向けの漢字書きとり練習アプリです。単一のHTMLファイルのみで動作し、完全オフラインで使えます。

## 使い方

`kanji-practice.html` をブラウザで開くだけです。インストールやビルドは不要です。

## 特徴

- 完全オフライン・通信ゼロ（外部サーバーへの通信は一切行いません）
- 学習記録はすべて端末内（localStorage）に保存され、外部には送信されません
- 小学校学年別漢字配当表 第3学年（200字）に準拠
- 白紙に記憶で書く「想起」重視の練習方式
- 書いた文字の形・書き順を自動採点（形が合ってから書き順を判定）
- ポイント・レベル・相棒育成などのゲーミフィケーション要素（課金要素なし）
